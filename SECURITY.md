# Security Policy

To report a security issue in this repository or in any Datacoves product, email **security@datacoves.com**, or use GitHub's private vulnerability reporting from the Security tab of this repository.

Please don't open a public issue or pull request for a security problem.

Include the affected repository or component and version, what the issue is, and steps to reproduce.

We'll acknowledge your report within 3 business days.

**Our full security policy, including scope and safe harbor terms, is at https://datacoves.com/security.** Please read it before you begin testing - in particular, several repositories in this organization are forks of upstream projects, and issues in upstream code should go to those maintainers instead.
